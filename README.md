# AI Tools Lab

## Project Description

AI Tools Lab is a beginner-friendly Python project that demonstrates
sorting algorithms and useful utility functions.

The project includes:
- Bubble Sort
- Palindrome checking
- Word counting
- Celsius to Fahrenheit conversion

The project is created as part of a college laboratory exercise to practice
Python programming, Git, GitHub, and AI-assisted development.
